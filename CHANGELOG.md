## [0.1.0] — unreleased

### Added
- MemPalace fork (MIT) for persistent memory
- CLI with command execution (`agentik run "command"`)
- XDD Adapter for pipeline integration
- HMAC-SHA256 receipts for audit trail
- Command history persistence
- Pipeline execution engine for `.xdd` files
- Metrics export (JSON and Prometheus format)
- Structured logging (JSON)
- GitNexus code analysis integration
- Security audit tools (semgrep, gitleaks, trivy, nuclei)
- Unit tests (11 tests passing)
- GitHub Actions CI workflow
